# Stage 82: Controlled waterfall experiment plans

The benchmark report now includes `waterfall_experiment_plans`, derived only from Stage 81 advisories. Eligible plans compare two provider orders (favored provider first versus the reverse) in the same field, Engine path, enrichment profile, and research lane. They specify controls to hold constant, measures to review, and safety guardrails. The optional Markdown brief lists each proposed A/B order.

These are plans only. The scorer does not create or edit waterfall JSON, contact providers, run leads, or send outreach. The experiment should use the same approved lead sample and keep acceptance thresholds, stop rules, call budget, currency, and pricing configuration fixed between variants. Review result coverage, correctness, identity, evidence, freshness, costs, failures, and unknown prices. The minimum reviewed-pair count is only a caution threshold, not a power guarantee.
