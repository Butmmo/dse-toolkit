# Stage 108: Keep assignment outputs separate by experiment

Assigned CSV and audit filenames now include the validated experiment ID, for example `paired-enrichment-test-2026-11-outreach-assigned.csv`. This lets the same paired source produce separate Engine import files for distinct experiments without a filename collision. It also makes the intended experiment visible when reviewing an Engine's imports.

Experiment IDs are restricted to 1–80 letters, numbers, dots, underscores, or hyphens, starting with a letter or number. This validation applies to direct CLI calls as well as HQ Tools. Re-running the same experiment/source path is idempotent when the generated bytes match; if an existing assignment or audit has different contents, the command refuses to replace it.

HQ Tools output discovery continues to match the assigned CSV and its companion audit JSON. Explicit `--out` paths remain available for standalone CLI use.

Validation for this slice: Python compilation, CLI help, and `git diff --check`; no test suite was run.
